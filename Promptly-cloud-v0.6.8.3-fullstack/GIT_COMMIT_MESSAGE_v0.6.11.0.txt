CREATE TABLE checkout_sessions (
  id TEXT PRIMARY KEY,
  user_id TEXT NOT NULL,
  stripe_session_id TEXT NOT NULL UNIQUE,

## 🔐 Security & Reliability

1. **Idempotency Protection**
   - 1-hour window reuses existing pending sessions
   - Prevents duplicate charges

2. **Session Recovery**
   - sessionStorage preserves state on refresh
   - Auto-recovery of interrupted flows

3. **Auth Context Preservation**
   - Inline Auth Modal (no redirect)
   - Login/register without losing plan selection

4. **Payment Verification Loop**
   - Polls /verify-session every 2s
   - Max 30 retries (60s timeout)
   - Network error resilience

5. **Error Tracking**
   - Analytics captures all failure points
   - Enables funnel bottleneck analysis

### SQL Queries
```sql
-- Auth conversion
SELECT 
  SUM(CASE WHEN event = 'AUTH_MODAL_OPENED' THEN 1 ELSE 0 END) as opens,
  SUM(CASE WHEN event IN ('AUTH_LOGIN_SUCCESS', 'AUTH_REGISTER_SUCCESS') THEN 1 ELSE 0 END) as success
FROM analytics_events
WHERE created_at > datetime('now', '-7 days');

-- Checkout success rate
SELECT 
  SUM(CASE WHEN event = 'CHECKOUT_SESSION_CREATING' THEN 1 ELSE 0 END) as attempts,
  SUM(CASE WHEN event = 'CHECKOUT_SESSION_CREATED' THEN 1 ELSE 0 END) as created
FROM analytics_events;
```
