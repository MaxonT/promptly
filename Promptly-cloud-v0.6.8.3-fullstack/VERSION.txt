- ✅ 在 system prompt 中添加语言要求指令
- ✅ 保持技术术语为英文，自然语言使用目标语言

- ✅ POST /api/question-sessions/:sessionId/finalize 接收 language 参数
- ✅ 从 request body 或 session 读取语言偏好
- ✅ 将语言参数传递给 generateRawSpec()
- ✅ 添加日志输出当前使用的语言

用户界面选择中文 → 后端生成中文 prompt
用户界面选择日语 → 后端生成日语 prompt
