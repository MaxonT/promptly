# Promptly 附件功能使用指南

## 🎯 功能介绍

Promptly 现在支持在提示词增强过程中附加文件！您可以上传图片、视频、PDF等各种类型的文件，让LLM更好地理解您的需求。

---

## 🚀 快速开始

### 步骤1：访问Prompt Enhancer页面

1. 打开浏览器，访问 Promptly 前端
2. 导航到 **Prompt Enhancer** 页面（`enhancer.html`）

### 步骤2：输入提示词

在文本框中输入您的原始提示词，例如：
```
帮我分析这张产品截图，并写一段营销文案
```

### 步骤3：附加文件

1. 点击 **📎 Attach files** 按钮
2. 从您的电脑选择一个或多个文件
3. 支持的文件类型：
   - 🖼️ 图片（PNG、JPG、GIF、WebP等）
   - 🎬 视频（MP4、AVI、MOV等）
   - 📄 文档（PDF、DOCX、TXT等）
   - 📦 压缩包（ZIP、RAR等）
   - 📝 任意其他文件

### 步骤4：查看附件列表

选择的文件会显示在列表中，每个文件显示：
- **图标**：根据文件类型显示（🖼️📄🎬等）
- **文件名**：完整的文件名
- **大小**：自动格式化（KB/MB）
- **移除按钮（×）**：点击可移除该文件

### 步骤5：增强提示词

1. 选择增强模式：
   - **Structure first**：结构化优化
   - **Style & tone**：风格和语气优化
   - **Simplify**：简化和精炼
2. 点击 **Enhance prompt** 按钮
3. 等待几秒钟，增强后的提示词会显示在右侧

### 步骤6：使用结果

- **复制增强后的提示词**：点击 "Copy enhanced prompt"
- **评分**：点击 "Score quality" 查看质量评分
- **验证**：点击 "Validate" 检查潜在问题

## 💡 使用场景

### 场景1：图片分析

**原始提示**：
```
分析这张图片
```

**操作**：
- 附加：`product_screenshot.png`
- 选择：Structure first
- 点击：Enhance prompt

**增强后的提示**：
```
请详细分析附加的产品截图（product_screenshot.png），包括：
1. 视觉元素：布局、颜色、字体
2. 用户界面：功能模块、交互设计
3. 设计风格：整体美学和品牌感
4. 改进建议：3-5条具体的优化方向

输出格式：结构化列表，每项包含标题和详细说明
```

### 场景2：多文件上下文

**原始提示**：
```
写一份产品发布公告
```

**操作**：
- 附加多个文件：
  - `product_features.pdf` - 功能列表
  - `demo_video.mp4` - 演示视频
  - `logo.png` - 产品logo
- 选择：Style & tone
- 点击：Enhance prompt

**增强后的提示**：
```
基于提供的产品资料（功能PDF、演示视频、品牌logo），撰写一份专业的产品发布公告：

内容要求：
1. 开头：吸引人的产品介绍（50字内）
2. 核心功能：提取PDF中的3-5个关键特性
3. 演示视频引用：引导用户观看演示
4. 品牌调性：符合logo体现的品牌风格
5. 行动号召：引导用户试用或购买

语气：专业、热情、易读
长度：300-500字
格式：适合用于官网和社交媒体
```

### 场景3：文档总结

**原始提示**：
```
总结这份报告的要点
```

**操作**：
- 附加：`quarterly_report.pdf`
- 选择：Simplify
- 点击：Enhance prompt

**增强后的提示**：
```
请阅读附加的季度报告PDF，提取并总结：

1. 关键数据（3-5个核心指标）
2. 主要成就（2-3项亮点）
3. 挑战和问题（1-2个关注点）
4. 下季度计划（简要概述）

输出格式：
- 使用项目符号
- 每项不超过30字
- 避免专业术语
- 适合向非技术团队汇报
```

## ⚙️ 高级功能

### 文件大小警告

选择大于10MB的文件时，系统会弹出确认对话框：
```
"large_video.mp4" is 15.2 MB. Large files may take time to upload. Continue?
```

- 点击 **OK**：继续添加文件
- 点击 **Cancel**：取消，不添加该文件

### 批量选择文件

1. 点击 "📎 Attach files"
2. 在文件选择对话框中：
   - **Windows**：按住 Ctrl 点击多个文件
   - **Mac**：按住 Command 点击多个文件
   - 或者：拖动鼠标框选多个文件
3. 点击 **打开**，所有文件会依次添加到列表

### 移除特定文件

- 每个文件右侧有 **× 按钮**
- 点击即可移除该文件
- 不影响其他文件

### 清空所有附件

- 成功发送请求后，附件列表会自动清空
- 或者：逐个移除所有文件

## ❓ 常见问题

### Q1: 支持哪些文件类型？

**A**: 几乎所有类型！包括但不限于：
- 图片：PNG, JPG, GIF, WebP, SVG
- 视频：MP4, AVI, MOV, WMV
- 文档：PDF, DOCX, TXT, MD
- 数据：JSON, XML, CSV, XLSX
- 压缩：ZIP, RAR, 7Z
- 代码：JS, PY, HTML, CSS

### Q2: 文件大小限制是多少？

**A**: 
- **推荐**：< 10MB（最佳性能）
- **警告**：10MB - 50MB（会提示）
- **限制**：后端默认限制为 2MB（可在 `server.js` 中调整）

如需上传大文件，请联系管理员调整后端配置。

### Q3: 附件会被保存吗？

**A**: 当前版本**不保存**文件内容。附件信息仅用于当次请求：
- ✅ 文件名、大小、类型被记录到日志
- ✅ 文件信息添加到LLM上下文
- ❌ 文件内容不存储到数据库
- ❌ 文件内容不上传到云存储

未来版本将支持附件持久化存储。

### Q4: LLM能看到图片内容吗？

**A**: **当前版本不能**。系统仅将文件元数据（文件名、大小、类型）转换为文本描述，例如：
```
--- Attached Files ---
  1. [IMAGE] screenshot.png (120.5 KB)
  2. [PDF] report.pdf (456.2 KB)
--- End of Attachments ---
```

**未来升级**将支持：
- 📷 图片视觉分析（GPT-4V）
- 📄 PDF文本提取
- 🎬 视频关键帧分析

### Q5: 纯文本请求还能用吗？

**A**: **完全可以**！附件功能是可选的：
- 不添加附件，直接点击 "Enhance prompt" 即可
- 行为与之前完全相同（向后兼容）

### Q6: 可以重复选择同一个文件吗？

**A**: 可以。每次选择都会添加到列表中（即使文件名相同）。

### Q7: 移除文件后可以撤销吗？

**A**: 不可以。移除后需要重新选择该文件。

### Q8: 移动端支持吗？

**A**: 支持！界面会自动适配手机和平板：
- 按钮区域会换行
- 附件列表保持清晰可读
- 文件选择对话框由系统提供

## 🔧 故障排除

### 问题1：点击"Attach files"没反应

**可能原因**：
- 浏览器禁用了文件访问权限
- JavaScript被禁用

**解决方法**：
1. 检查浏览器控制台（F12）是否有错误
2. 确保浏览器允许JavaScript
3. 刷新页面（Ctrl+R / Cmd+R）

### 问题2：文件添加后列表不显示

**可能原因**：
- CSS未加载
- 文件读取失败

**解决方法**：
1. 硬刷新页面（Ctrl+Shift+R / Cmd+Shift+R）
2. 检查浏览器控制台错误信息
3. 尝试选择更小的文件（< 1MB）

### 问题3：点击"Enhance"后显示错误

**可能原因**：
- 后端未启动
- OpenAI API密钥未设置
- 网络连接问题

**解决方法**：
1. 检查后端状态：访问 `http://localhost:8080/api/health`
2. 查看浏览器控制台的网络请求
3. 联系管理员检查服务器状态

### 问题4：大文件上传很慢

**可能原因**：
- 文件太大（>10MB）
- 网络速度慢
- Base64编码开销

**解决方法**：
1. 压缩文件后再上传
2. 选择更小的文件
3. 等待上传完成（避免刷新页面）

## 💡 最佳实践

### 1. 文件命名

使用描述性的文件名：
- ✅ `product_feature_screenshot.png`
- ❌ `IMG_1234.png`

好处：增强后的prompt会引用文件名，描述性名称更有帮助。

### 2. 文件数量

建议每次附加 **1-5个文件**：
- 太少：可能上下文不足
- 太多：可能让LLM难以处理

### 3. 文件大小

优先选择压缩后的文件：
- 图片：使用JPEG而非PNG（如不需要透明度）
- PDF：使用"优化PDF"功能
- 视频：选择较低分辨率或使用压缩工具

### 4. 提示词配合

在文本中明确引用附件：
```
请分析附加的产品截图（screenshot.png）...
```

而不是：
```
分析这个图片...
```

### 5. 增强模式选择

- **Structure first**：适合需要详细说明的场景
- **Style & tone**：适合需要调整语气的场景
- **Simplify**：适合需要精炼表达的场景
