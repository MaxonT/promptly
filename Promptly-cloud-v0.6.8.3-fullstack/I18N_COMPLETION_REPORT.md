### 关键功能

#### 1. 语言检测优先级
```javascript
1. localStorage.getItem('locale')  // 用户上次选择
2. navigator.language              // 浏览器语言
3. 'en'                           // 默认英语
```

#### 2. RTL 语言支持
```javascript
RTL 语言列表: ['ar', 'he', 'fa', 'ur']
自动设置: document.documentElement.dir = 'rtl'
```

#### 3. 缓存机制
```javascript
缓存前缀: 'i18n_cache_'
过期时间: 24 小时
存储位置: localStorage
```

#### 4. 动态加载
```javascript
按需加载: 仅加载用户选择的语言
网络优化: 优先使用缓存
回退机制: 加载失败使用英语
```

## 🚀 快速补充翻译指南

### 方法 1: 使用 AI 翻译（推荐）

```bash
# 1. 导出需要翻译的键
python3 check_i18n.py --export-missing en > missing_en.json

# 2. 使用 ChatGPT/Claude 翻译
# Prompt: "Please translate the following JSON to English, maintaining the structure and keys..."

# 3. 合并翻译
python3 check_i18n.py --merge en < translated_en.json
```

### 方法 2: 手动翻译

1. 打开 `frontend/locales/zh-CN.json`（参考）
2. 打开 `frontend/locales/en.json`（目标）
3. 找到缺失的键
4. 逐一翻译并添加
