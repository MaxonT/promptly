# Promptly

AI prompt optimization studio: turn a rough goal into a clearer prompt through Spec → Questions → Candidates → Metrics → Outcome.

Don’t want to configure an API key? Use the hosted product: **[https://promptly.solutions/](https://promptly.solutions/)**  
(also linked from Releases)

**Core product code lives on `cursor-dev`.**  
`main` is the public entry / docs branch for the repo and cloud-facing notes. Day-to-day app work happens on `cursor-dev`.

Current runnable tree: [`Promptly-cloud-v0.6.8.3-fullstack/`](Promptly-cloud-v0.6.8.3-fullstack/)

## Quick start (local)

Work inside the fullstack folder:

```bash
cd Promptly-cloud-v0.6.8.3-fullstack
```

### 1. Backend

```bash
cd backend
cp .env.example .env
# set at least: JWT_SECRET + OPENAI_API_KEY
npm install
npm run dev                  # http://localhost:8080 (migrations on start)
```

Minimum env for AI features:

| Variable | Purpose |
|----------|---------|
| `JWT_SECRET` | JWT signing (required in production; long random string) |
| `OPENAI_API_KEY` | OpenAI access — without it, LLM / pipeline features are disabled |
| `OPENAI_MODEL` | Optional (default in example: `gpt-4.1-mini`) |
| `CORS_ORIGIN` | Allowed frontend origin(s), comma-separated |
| `SQLITE_PATH` | Local DB (default `./data/app.db`) |
| `DATABASE_URL` | Set to use PostgreSQL instead of SQLite |
| `GROQ_API_KEY` | Optional Groq path for some inference profiles |
| `FRONTEND_URL` | Stripe / OAuth redirect base |
| `GOOGLE_*` / `GITHUB_*` | OAuth (optional) |
| `STRIPE_*` / `SUBSCRIPTIONS_ENABLED` | Billing (optional) |

Full list: [`backend/.env.example`](Promptly-cloud-v0.6.8.3-fullstack/backend/.env.example)

### 2. Frontend

```bash
cd frontend
# point API at local backend, then serve static files
VITE_API_BASE=http://localhost:8080 npm run build
python3 -m http.server 4173
```

Open `http://localhost:4173/index.html`.  
Pages read `window.PROMPTLY_API_BASE` from `config.js` (generated by `npm run build`).

### 3. Smoke checks

```bash
cd backend && npm run health
curl http://localhost:8080/api/health
```

## Tech stack

| Layer | Choice |
|-------|--------|
| Frontend | Static HTML / CSS / JS (`config.js` build injects API base) |
| Backend | Node.js ESM + Express |
| Database | SQLite locally; PostgreSQL when `DATABASE_URL` is set |
| Auth | JWT + bcrypt; Google / GitHub OAuth |
| AI | OpenAI (primary); Groq optional via `GROQ_API_KEY` |
| Billing | Stripe (optional) |
| Deploy | Render (API) + Vercel or static host (frontend) — see nested docs |

---

## Architecture (short)

```
Browser (static frontend)
    │  fetch + Bearer JWT
    ▼
Express /api/*  (auth, oauth, pipeline, specs, questions, enhance, outcome, billing, analytics…)
    │
    ├─► SQLite or PostgreSQL
    ├─► OpenAI / Groq (Spec → Questions → Agents → Metrics → Outcome)
    └─► Stripe (optional)
```

Core optimization flow: `/api/pipeline/*` (`run`, `health`, `stream/:runId`).

## 本地快速开始

进入 fullstack 目录：

```bash
cd Promptly-cloud-v0.6.8.3-fullstack
```

### 1. 后端

```bash
cd backend
cp .env.example .env
# 至少配置：JWT_SECRET + OPENAI_API_KEY
npm install
npm run dev                  # http://localhost:8080（启动时跑迁移）
```

AI 功能最少需要：

| 变量 | 作用 |
|------|------|
| `JWT_SECRET` | JWT 签名（生产必填；用足够长的随机串） |
| `OPENAI_API_KEY` | OpenAI 访问 — 不配则 LLM / pipeline 不可用 |
| `OPENAI_MODEL` | 可选（示例默认 `gpt-4.1-mini`） |
| `CORS_ORIGIN` | 允许的前端源（逗号分隔） |
| `SQLITE_PATH` | 本地库路径（默认 `./data/app.db`） |
| `DATABASE_URL` | 设置后走 PostgreSQL |
| `GROQ_API_KEY` | 可选，部分推理配置走 Groq |
| `FRONTEND_URL` | Stripe / OAuth 回跳基址 |
| `GOOGLE_*` / `GITHUB_*` | OAuth（可选） |
| `STRIPE_*` / `SUBSCRIPTIONS_ENABLED` | 订阅（可选） |

完整列表见 [`backend/.env.example`](Promptly-cloud-v0.6.8.3-fullstack/backend/.env.example)

### 2. 前端

```bash
cd frontend
VITE_API_BASE=http://localhost:8080 npm run build
python3 -m http.server 4173
```

打开 `http://localhost:4173/index.html`。  
页面通过 `config.js` 里的 `window.PROMPTLY_API_BASE` 找后端。

### 3. 冒烟检查

```bash
cd backend && npm run health
curl http://localhost:8080/api/health
```
