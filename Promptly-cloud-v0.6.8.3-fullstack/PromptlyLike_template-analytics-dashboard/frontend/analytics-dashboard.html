📖 Metrics Glossary

Total Users

Formula: COUNT(*) FROM analytics_users

The cumulative count of all registered users on the platform since launch. This includes both active and inactive accounts.

DAU (Daily Active Users)

Formula: COUNT(DISTINCT user_id) FROM sessions WHERE date = today

The number of unique users who initiated at least one session on a specific day. A user is counted only once regardless of session count.

WAU (Weekly Active Users)

Formula: COUNT(DISTINCT user_id) FROM sessions WHERE date > today - 7

Unique users active within the past 7 days. Each user counted once even if active on multiple days.

MAU (Monthly Active Users)

Formula: COUNT(DISTINCT user_id) FROM sessions WHERE date > today - 30

Unique users active within the past 30 days. Each user counted once regardless of activity frequency.

Stickiness (DAU/MAU Ratio)

Formula: (DAU / MAU) × 100%

Measures user retention and engagement. Higher values = users return frequently. Benchmark: 20-25% good, >50% excellent.

Bounce Rate

Formula: AVG(sessions with 1 page view) / Total Sessions

Percentage of single-page sessions. Lower is better; >40% typically indicates UX issues.

⚠️ S-Curve Growth Model

Formula: f(x) = L / (1 + e^(-k(x - x0)))

L = target users (asymptote), k = growth rate, x0 = inflection point (day reaching 50% users)
